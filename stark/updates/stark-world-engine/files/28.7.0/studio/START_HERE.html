Stark World Engine 28.7.0 - Studio

Build a game. Share it as one file. One install, endless ideas.

Stark World Engine - a Stark product. Holiday 2026 Edition. Everything runs on your own computer, offline. No account, no subscription, no cloud AI.

Start

  1. Unzip this folder (right-click > Extract All). You need a current Chrome, Edge or Firefox. Nothing else to install: Python comes built in.
  2. Windows: double-click START_STARK_WORLD_ENGINE.bat. Mac: double-click start_stark_world_engine.command (the first time: right-click > Open > Open; needs Python 3.10+ from python.org). Linux: bash start_stark_world_engine.sh. Your browser opens the studio at http://127.0.0.1:8505 (or the next free port up to 8520). It listens on this computer only.
  3. Click Make me a game for an instant playable game, pick a starter world (Firefly Fen, Summit Snack Run, Lantern Leap), or make a new 3D/2D world.

Your Studio edition comes activated (key.txt is included): Godot 4 / UE5 export is unlocked from the first start. Got a separate key instead? Paste it into Export > Activate. Details: ACTIVATION.md.

Help: open HELP.html (works offline: quick start, user guide, tutorials, FAQ, troubleshooting). Something not working? The launcher checks your setup every time and tells you exactly what to do.

What is inside

  • 3D builder with PBR lighting, HDRI skies, soft shadows and five Living World Moods (Bioluminescent Twilight, Alpine Sunset, Sub-Zero Aurora, Crimson Citadel, Sunken Ruins), weather, hit-stop combat, Cinematic Drone Mode (P) and Postcard PNG.
  • Bundled CC0 art: Quaternius characters (with Universal Animation Library moves), village and nature kits; Poly Haven skies and ground textures. Credits: assets/CREDITS.txt.
  • 2D builder: tile painter + platformer with the same moods.
  • Pixel-Art Canvas (16x16 sprite, PNG export) and WAV SFX Forge.
  • Single-file HTML5 3D Cartridge export (one .html you can share or upload; it runs offline).
  • Godot 4 and UE5 project export (Pro/Studio).
  • New in 28.7: variables and on-screen counters, repeating / key / variable triggers, touch controls and gamepads in exported games, read-aloud with offline voices, Tune Maker music inside exported games, six guided tutorials (Learn tab), remix a shared game, copy / paste / duplicate and snap, a Watch panel, and an itch.io-ready zip.
  • UI in 8 languages (EN, ES, FR, DE, PT, IT, JA, ZH).

Creator suite (Studio)

First time: double-click SETUP_STARK_WORLD_ENGINE.bat. The 5-minute Setup Wizard checks FFmpeg and OBS, lets you pick your camera and mic, connects your phone with a QR code, records a test clip and auto-edits it. After that, double-click START_CREATOR_HUB.bat to run everything.

  • OBS bridge: writes an OBS profile + scene collection (camera, iPhone camera via VDO.Ninja, screen, mic with RNNoise) and enables obs-websocket.
  • Auto editor: edits new recordings: beat-synced cuts, grade, captions, -14 LUFS, 3 vertical clips.
  • Phone hub: login-protected Command Center on your home Wi-Fi (scheduler, teleprompter, review & approve, stats).
  • Publishing runs only after you approve: YouTube upload with your own free Google API project; X / Instagram / Substack get drafts and their compose page - you post yourself.

Needs Windows, OBS Studio 30+, FFmpeg (the Setup Wizard helps you install both). Optional local AI captions: Ollama.

Your worlds live in My_Games/; every save keeps the 3 previous versions in My_Games/.backups/.
